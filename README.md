# inbound-triage-assistant

An assistant for triaging inbound messages.

## Status

Early scaffolding — no implementation yet.

## Getting started

```bash
git clone https://github.com/malharlakdawala/inbound-triage-assistant.git
cd inbound-triage-assistant
```

## Notes

This repository is public. Do not commit API keys, credentials, or customer
data. Keep secrets in a local `.env` file (already gitignored).
